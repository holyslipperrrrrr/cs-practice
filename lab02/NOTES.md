&#x20;Рабочая папка

Папка с файлами проекта, где я работаю. Внутри спрятана .git - там Git хранит историю.



&#x20;Индекс

Промежуточная зона. Файл попадает сюда после git add, но ещё не сохранён.



&#x20;Коммит

Сохранённая точка в истории. У неё есть автор, дата и сообщение.



Git и GitHub - в чём разница

Git - программа на компьютере, хранит историю локально.

GitHub - сайт, куда эту историю можно залить и делиться с другими.



Использованные команды

git status - показывает, что происходит: какие файлы изменены, что в индексе, что ещё нет.

git diff - показывает изменения в файлах, которые ещё не добавлены в индекс (до git add).

git diff --staged - показывает изменения, которые уже в индексе



Ветка - это отдельная линия разработки. Можно менять файлы, не трогая main.

При новом коммите ветка сдвигается вперёд — начинает указывать на новый коммит.

Слияние - это перенос изменений из одной ветки в другую.
